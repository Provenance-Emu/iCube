### The redundancy trap — read before merging any old branch

Every remaining workstream branch LOOKED substantial and was entirely superseded. The check that
catches it is per-file, not per-commit:

```bash
for f in $(git diff --name-only $(git merge-base develop $B) $B); do
  git cat-file -e develop:"$f" 2>/dev/null || { echo "ABSENT: $f"; continue; }
  git diff --quiet develop:"$f" $B:"$f" || echo "differs: $f"
done
```

Zero "ABSENT" files means nothing is unshipped. WS-1 was the worked example: 3 of 6 files
byte-identical, and merging it would have REGRESSED three things (restored a controller call WS-2
replaced, removed WS-4's sharing button, un-localized a string). A conflict on these branches means
*stale*, not *pending*.

Also: `SettingsRootView.swift` inflated four branches by ~4400 lines each. `develop` already split
that monolith into 24 files; the branches carry the pre-split copy.

## Performance: stop optimizing the interpreter

Three targets, all far under their headline. Details in the memory notes; the short version:

| target | headline | reality |
|---|---|---|
| A gather-pipe stores | 16.5% of cycles | already fast-pathed by `620ef7a993`; fusion measured <1%, inside the error bars |
| B FP/PS generic dispatch | 19.4% | mislabeled ~3x; real tax 5.8%, and every opcode is ALREADY whitelisted — one flag flip |
| C dyn_link 75% hit rate | 25% misses | real: fixed to 99.6%, killing 98.7% of dispatcher round-trips — but only ~+1.1% throughput |

Measured on the four previously-slow titles with the user's flags on, all at full emulated speed and
**0.00% generic dispatch**: F-Zero GX 59.9 vps, NFS Underground 59.5, GoldenEye Rogue Agent 55.4,
Pokemon Colosseum 59.9 (hung). There is no instruction-level headroom left worth chasing. NFS needs
~48% more throughput before its adaptive clock stops underclocking, which only JIT delivers, and JIT
is sideload-only (never App Store).

**Device measurement is the binding constraint**, not ideas: per-leg noise is ~2%, so the standard
error on any A/B comparison is ~1.5% — larger than any remaining candidate win.

## Gotchas worth carrying forward

- `git merge`, do NOT cherry-pick these old branches: their final trees merge cleanly but individual
  commits do not replay.
- `git checkout -- build/xcframework` before EVERY commit; local app builds rewrite the tracked
  slices.
- zsh does not word-split unquoted variables — `set -A arr ...` + `"${arr[@]}"` in loops.
- The bench's `replace` mode resets every key to its DEFAULT first, which silently changed the CPU
  core and later dual-core. Defaults != a sane running config.
