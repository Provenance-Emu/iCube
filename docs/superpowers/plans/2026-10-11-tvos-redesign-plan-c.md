# tvOS redesign completion, plan C: pause completion

> Lean plan by owner ruling (velocity mode): tasks name files, token rules and acceptance; implementers read the code and write it without builds. Spec: `docs/superpowers/specs/2026-10-11-tvos-redesign-completion-design.md` §6. The pause grid itself is done (`MenuScreen.tvTilesBody`, `ICubeTileButtonStyle`, `InfoShelf`); this plan finishes the sub-screens and adds the new tiles.

**Global constraints:** as plan A. Pause code is shared with iOS: gate every visual change with `#if os(tvOS)` unless the spec says the tile grid is shared (new tiles ARE shared: they appear on both platforms). `PauseArbiter` owns pausing; never call the bridge's pause/resume from UI (`CorePauseCallSitesTests` enforces it).

**Shared names (write against these even if another task has not landed them yet):**
- `TVEmulationBridge`: `+ (NSInteger)internalResolution` / `+ (void)setInternalResolution:(NSInteger)scale` (Dolphin `Config::GFX_EFB_SCALE`, 0 = auto, 1 = native, 2 = 2x, …), `+ (NSInteger)audioVolumePercent` / `+ (void)setAudioVolumePercent:(NSInteger)percent` (`Config::MAIN_AUDIO_VOLUME`), all via `Config::SetCurrent` / `Config::Get`. (C4)
- `CpuEngine.resolved(stored: CpuEngine, acquiredJit: Bool) -> CpuEngine` (JIT engines fall back to `.cachedInterpreter` when JIT is not acquired, matching `PerformanceTuningState`) and `CpuEngine.shortName: String` ("INT", "CIR", "CIR-IR", "JIT"). (C4, new file)
- `PauseMenuView.init(..., onShowSettings:, onShowSettingsLeaf: @escaping (String) -> Void = { _ in }, onShowPerfOverlay:, ...)` and `PauseMenuActions.openSettingsLeaf: (String) -> Void`. (C1 declares, C5 wires)
- `PauseMenuState` gains `internalResolution: Int`, `audioVolume: Int`, `engineShortName: String`, `jitAcquired: Bool`. `PauseMenuBindings` gains `internalResolution: Binding<AnyHashable>`, `audioVolume: Binding<AnyHashable>`. (C1)
