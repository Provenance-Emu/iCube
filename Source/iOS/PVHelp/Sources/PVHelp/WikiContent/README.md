# Welcome to the iCube Wiki

iCube is a GameCube and Wii emulator for iOS and tvOS, forked from OatmealDome's
DolphiniOS, itself built on the Dolphin emulator.

This wiki is bundled inside the app so it works even with no network connection —
the pages you're reading right now are the same ones shipped in the app under
**Settings → Help**. If you're reading this on GitHub, you're looking at the
source of truth; the app's copy refreshes from here automatically once this repo
is public, and falls back to the pages it shipped with until then.

## Start here

Use the list on the left (or, in the app, the Help section's page list) to jump
to a topic. The most-asked-about ones:

* **Wi-Fi / Web Import** — get GameCube and Wii files onto your device
  without a cable.
* **Dumping GameCube & Wii Discs** — make a disc image from a disc you own with
  a Wii and CleanRip, then shrink it to RVZ.
* **WiiWare, Virtual Console & Channels** — dump a title to a `.wad`, or import
  a BootMii NAND backup.
* **Install Your Own Wii System Files** — import the System Menu and IOS from a
  BootMii backup of your own Wii, on iPhone, iPad and Apple TV.
* **GameCube BIOS (IPL)** — what the GameCube BIOS is, whether you need it,
  and where it goes.
* **Save State Compatibility** — why a save state can go stale across
  updates, and how to avoid losing progress.

## Re-signed installs

If you run a copy of iCube that was re-signed with debugging entitlements
rather than the App Store build, the **JIT & Performance (iOS 26)** page
explains what JIT does and how to switch it on. It is listed in Help only
when iCube detects that JIT can work.

## Getting help beyond this wiki

If a page here doesn't answer your question, visit icube-emu.com/support.
